# FinAI · Геймификация — прототип

Кликабельный HTML-прототип геймификации платформы FinAI. Баллы, уровни и достижения считаются по-настоящему и общие для всех разделов.

**Открыть:** `index.html` (или GitHub Pages этого репозитория).

## Сценарии
- **Мои задачи** — плитка задач по макету, серия без просрочек, цель дня, баллы за неделю, архив, оценка раздела (CSAT).
- **Карточка инициативы** — согласование: кнопка становится зелёной с галочкой, маршрут обновляется; первое согласование и вехи 10/25/50/100 — модалка с Финни и конфетти, остальные — нотификация.
- **Заявки** — форма с прогрессом заполнения, отправка, «Ваша первая заявка», прохождение маршрута.
- **Отчёты** — «Путь аналитика»: 6 целей по +10 баллов, уровни «Уверенный пользователь» (3 из 6) и «Эксперт отчётов» (6 из 6).
- **Кабинет достижений** — два варианта: каталог и «Мой уровень»; уровни Новичок → Практик → Эксперт → Лидер эффективности.

## Правила уведомлений
- Не больше одной модалки за сессию (исключение — «Эксперт отчётов!»).
- Рутинные нотификации — не чаще раза в 30 секунд; пропущенные попадают в центр уведомлений (колокольчик).
- Нотификации о достижениях идут через 500 мс, о новом уровне — через 300 мс после последней; висят 6 с и не скрываются под курсором.
- `prefers-reduced-motion` — без конфетти и прыжков, только затухание.

Демо-панель внизу запускает ключевые моменты: первое согласование, веха 10, почти «Практик», одна задача до конца, отчёты 5 из 6, сброс.
